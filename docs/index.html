COURSE PROJECT

SupplyFlow Lab · 供应链运营与补货决策看板

基于 Aklilu Abera / Supply-Chain-Dashboard（MIT）研习与改进。原作提供模拟业务数据、Prophet 需求预测、库存规则和 Streamlit 看板；本项目新增浏览器端决策工作台与情景计算，保留原作者署名及许可。

01 / 采购视角

从订单数量扩展到采购金额、品类结构和供应商金额集中度。

02 / 计划视角

加入库存覆盖天数、经验交期、在途量、备货周期和订货批量情景。

03 / 行动视角

风险排序、网点与品类筛选、可下载补货清单，以及公开免登录演示。

指标口径
  • 采购金额：订单数量 × 单价，不含税费和物流成本；源数据未注明币种。
  • 准时交付率：已完成交付订单中的 on_time_delivery=True 数 / 已完成交付订单数。未根据缺失的承诺日期重新判断。
  • 实际交期：已完成订单的交付日期 − 下单日期，按订单等权平均。
  • 经验交期：各 SKU × 网点的历史已完成订单平均交期；缺失时采用原项目交期。
  • 库存覆盖天数：在手库存 / 情景日均需求；无需求时记为不适用。
  • 目标库存：情景日均需求 ×（经验交期 + 备货周期）+ 情景安全库存。安全库存按需求比例线性缩放，为简化假设。
  • 预估补货金额：建议数量 × 产品主数据单位成本，为资金测算值，不是供应商报价。
数据与使用边界

全部为上游生成的模拟数据。采购仅展示快照年度，库存为单日快照；采购期间筛选不会改变库存。模拟在途量依据快照日尚未交付的订单推导。没有预留库存、欠单、真实 MOQ、交付排程、仓容与预算约束，不能直接用于企业下单。

当前演示沿用原作历史日均需求，不宣称重新训练了预测模型，也未验证节省成本或提升效率。源数据中交付结果、库存与需求未必完全勾稽；本项目用于学习指标定义、发现问题和比较情景。
